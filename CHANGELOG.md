# Changelog

## 2.0.0
- Redesigned dashboard: grouped navigation, status overview with welcome checklist and shortcuts, richer live preview (wallpaper, glass, typography), sticky Apply bar.
- Redesigned popup: site status, per-site theme override, quick actions, Focus switch.
- Automation: automatic theme by time of day or system light/dark; optional daily time limits per supported site with a snoozable reminder.
- Keyboard shortcuts (Alt+Shift+N on/off, F Focus Mode, P pick element) and an OFF badge on the toolbar icon when paused.
- Backup and restore of all settings (optionally with wallpapers) with validation.
- Built-in wallpaper gallery (4 generated originals) and 5 new presets (Aurora, Rose Quartz, Sunset, Terminal, Mono Paper).
- Settings schema v2 with automatic upgrade; welcome page on first install.

## 1.3.0
- YouTube glass layout reworked for home, subscriptions, search, watch, channel, playlist, history and Shorts pages; YouTube Music support (best effort); Dusk Glass preset and one-click Dusk look with a bundled wallpaper.

## 1.2.0
- YouTube glass layout, greeting banner (date, "Good evening, <name>") and hero space.

## 1.1.0
- Ads hiding (known placements, Skip click), opt-in dislike count, YouTube channel/word blocklist, History shortcut, Instagram gallery mode (experimental), label rules in 11 languages.

## 1.0.0
- Themes, glass, wallpapers, typography, per-site profiles, CSS editor, element picker, theme import/export, Focus Mode adapters for YouTube, X, Instagram, Facebook and Reddit, tests, audit script, documentation.
